# FinSight Backend - Railway Deployment

This is the backend API for FinSight financial document analyzer.

## What's Included:
- Flask REST API
- PDF processing
- AI-powered transaction classification
- Excel & Word report generation
- Budget analysis

## Deploy to Railway:
1. Upload this folder to GitHub
2. Connect to Railway
3. Deploy automatically!

Your Railway URL will be: https://[your-app].up.railway.app
